# Что надеть?

Сайт, который показывает погоду в любом городе и подсказывает, как одеться: верхняя одежда, верх, низ, обувь и аксессуары. Данные о погоде настоящие, обновляются каждые 15 минут.

**Сайт:** https://grigorijg472-ops.github.io/Bond/projects/weather-outfit/

## Что умеет

- Показывает текущую погоду: температуру, ощущаемую температуру, ветер с порывами, влажность, вероятность осадков, УФ-индекс, восход и закат.
- Даёт почасовой прогноз на сутки и прогноз на 7 дней.
- Ищет любой город с подсказками и умеет определять местоположение.
- Подбирает образ на сейчас, на сегодня, на завтра или на любой день недели.
- Держит два гардероба, «Для неё» и «Для него». Кнопка «Другой вариант» собирает альтернативный комплект под ту же погоду.
- Даёт советы на день: про гололёд, сильный ветер, перепад температуры, крем от солнца.
- Меняет фон под погоду и время суток: дождь, снег, облака, туман, звёзды ночью, молнии в грозу.
- Запоминает выбранный город и гардероб и умеет делиться образом.

## Как подбирается одежда

Основа подбора: ощущаемая температура, в которой уже учтены ветер и влажность. По ней выбирается одна из восьми зон, от −15° и ниже до жары выше +26°. Для каждой зоны есть несколько вариантов вещей.

Потом комплект уточняется по погоде:

| Условие | Что меняется |
| --- | --- |
| Дождь или вероятность осадков от 45% | плащ или мембранная куртка, непромокаемая обувь, зонт |
| Сильный ветер | вместо зонта капюшон, совет про непродуваемую куртку |
| Снег | сапоги или ботинки с протектором, угги исключаются |
| Около нуля и осадки | предупреждение о гололёде |
| УФ-индекс от 3 | солнцезащитные очки, с 5 и выше в жару ещё панама или кепка |
| Перепад за день от 8° | совет одеться слоями и сумка для снятой вещи |

Для дней прогноза берётся дневная ощущаемая температура, а для «Сейчас» текущая погода и осадки на ближайшие 12 часов.

## Технологии

- HTML, CSS и JavaScript без фреймворков и без сборки.
- Погода и поиск городов: [Open-Meteo](https://open-meteo.com/), бесплатно и без API-ключа.
- Название места по геолокации: [BigDataCloud](https://www.bigdatacloud.com/) (бесплатный клиентский API).
- Иконки интерфейса: [Lucide](https://lucide.dev/) (SVG).
- Шрифты: Unbounded и Manrope из Google Fonts.
- Анимации: Canvas для неба, Web Animations API для вылета вещей из шкафа.

Контраст текста во всех темах не ниже 4.5:1, кнопки не меньше 44 px, есть видимый фокус для клавиатуры. Если в системе включено «Уменьшить движение», анимации отключаются.

## Запуск

Скачайте репозиторий и откройте `index.html` в браузере. Ничего устанавливать не нужно, нужен только интернет для загрузки погоды.

Если браузер не даёт определить местоположение при открытии файла с диска, запустите локальный сервер:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте репозиторий `weather-outfit` и загрузите в него все файлы из этой папки (кнопка **Add file → Upload files**, можно перетащить всё сразу).
2. Откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1-2 минуты сайт появится по адресу `https://<ваш-логин>.github.io/weather-outfit/`.

Если репозиторий называется иначе, поменяйте ссылку в начале этого файла.

## Структура

```

js/weather.js       загрузка погоды и поиск городов
js/outfits.js       подбор одежды и советы
js/effects.js       анимированное небо и вылет вещей из шкафа
js/app.js           логика интерфейса
```
